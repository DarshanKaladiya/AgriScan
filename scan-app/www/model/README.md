# AgriScan Mobile Model Bundle

This directory holds the quantized TensorFlow.js model files loaded directly by the AgriScan mobile app (`scan-app/www/js/model_service.js`).

## Expected Files:
1. `model.json`: Model topology and weight manifest generated by `tensorflowjs_converter`.
2. `group1-shard1of*.bin`: Quantized model weight binaries (float16/uint8).
3. `labels.json`: Exact array of 18 class keys matching the model's output neurons.

## How to Populate from Google Colab:
1. Run `ml/train_model.ipynb` on Google Colab (with free T4 GPU).
2. The notebook automatically downloads `agriscan_model_bundle.zip` upon completion.
3. Unzip the contents directly into this folder (`scan-app/www/model/`).

## Architecture Details:
- **Base Architecture**: MobileNetV2 with ImageNet transfer learning.
- **Input Resolution**: 224x224 RGB image.
- **Pixel Range**: **Raw 0 to 255** (Normalization is handled internally in the model graph via `tf.keras.applications.mobilenet_v2.preprocess_input`).
- **Loading API**: `tf.loadGraphModel('model/model.json')`
